# 功能裁剪记录

本仓库按产品决策逐步删除/收窄功能。此文件记录「砍了什么、什么时候砍的、
为什么、能否恢复」,避免后续误以为功能丢失是缺陷。

## 记录

| 功能 | 状态 | 版本(提交) | 日期 | 说明 |
|---|---|---|---|---|
| 单命令执行(run) | **已删除** | v0.1.1(`5e9137d`) | 2026-09-05 | `gossh run` 子命令、`POST /api/run`、前端 RunModal/RunView/运行页签全部移除,共删约 1009 行。理由:暂不需要。恢复需重写(无保留代码)。 |
| SFTP 文件传输 | **编译开关,默认关闭** | v0.1.1(`7605cd8`) | 2026-09-05 | 默认构建不含 `pkg/sftp` 与 `/api/**/sftp/*` 端点、前端中栏 SFTP 面板不渲染。启用:`make build SFTP=1`(Go `-tags sftp` + 前端 `VITE_ENABLE_SFTP=1`);代码与 CI 编译检查保留,可随时打开。理由:暂不需要,保持二进制精简。 |
| 跳板机(via) | **已删除** | v0.1.2(待发布) | 2026-09-05 | 主机记录 `via` 字段、连接链解析(`Chain`/`Parents`)、多跳 ProxyJump 拨号(`dialVia`)、`GET /api/hosts/{id}/parents`、前端跳板下拉/via 路径展示、CLI `--via` 全部移除。理由:暂不需要,拨号路径简化为单跳直连。恢复需重写。 |

## 说明

- 删除类功能(上表「已删除」)不在代码库保留实现,恢复意味着重新开发;
- 开关类功能(SFTP)代码在仓库内,只是默认不编译——CI 仍有 `-tags sftp`
  编译检查防止腐化;
- 每次裁剪同步更新 `CONTEXT.md`(领域术语)、`README`(功能与用法)与
  smoke 测试,保证文档与实现一致。
